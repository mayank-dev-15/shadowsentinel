## About

**shadowsentinel** is a ai-powered network intrusion detection.

### Key Features

- Real-time packet capture
- ML anomaly detection (Isolation Forest)
- MITRE ATT&CK mapping
- Alert generation
- FastAPI REST API
- React dashboard
- WebSocket alerts

---

## Tech Stack

- Python
- FastAPI
- React
- scikit-learn
- SQLite
- MITRE ATT&CK

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `Dashboard` | View alerts |
| `Packets` | Browse captured |
| `MITRE` | View ATT&CK matrix |
| `API` | REST endpoints |
| `Config` | Set thresholds |
